# HandTrack

Kontrol HP dengan tangan lewat kamera depan.

| Gestur | Aksi |
|---|---|
| Genggam (kepalan) | Gerakkan kursor |
| Jempol saja | Tap |
| Telunjuk saja | Geser atas |
| Jari tengah saja | Geser bawah |
| Jari manis saja | Geser kanan |
| Kelingking saja | Geser kiri |
| Telapak terbuka (tahan 1 dtk) | Kembali |

Cara pakai: genggam, arahkan kursor, lalu buka SATU jari sesuai aksi.
